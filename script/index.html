档案 · 网格文字

写给一个从未见过的声音。

信标带来的不再只是一幅图，翻译机就需要一种把它记下来的办法。这就是那套文字。它是我们对罗斯128 b 发来内容的转写，不是他们自己的书写；也没有人知道他们长什么样。它出自对他们说话方式的一个想法：一个声音单独只能说出很少的东西，声音汇合，意义才丰富起来。

1 · 网格

一张网格，每个声音一种记号

  • 一切都画在同一张共享的网格上。
  • 每一方只用自己的记号画：+ 是罗斯128 b，× 是我们。记号从不互相覆盖，所以总能看出是谁画的。
  • 一块 3 × 3 的格子是一个部件，两个部件组成一个词，就像笔画组成汉字。它不是字母表。
  • 一行是一句话。其他声音在它下面画出自己的回答。

到目前为止，他们发来的一切都只用 + 画成。图里的第二个声部是人类可以发回去的回答：是水，不是空气。

2 · 部件

十六个部件

每个部件是一个 3 × 3 的形状，有两种意思：作为事物的意思，和箭头后面作为关系的意思。形状尽量让人猜得出来：封闭的方块是我们，朝某人打开的方块是你们，交叉的光线是光，上升的台阶是声音。

    3 · 词

    两个部件组成一个词

    一个词占两个相邻的位置：左边是类，右边是指，写作 类.指。属于你们的世界是你们的世界；计时的恒星是脉冲星；行进的空气是风。只有一个部件的词，右边空着。所有约定好的词都在词典里。

      4 · 句

      每一行是图谱的一条边

      一行宽六个位置（23 格），正好放三个词：一个节点、一个关系、另一个节点。一段文字是一行行叠起来的，所以一段文字就是一张知识图谱。同一个词出现在两行，就是同一个节点；节点位置上单独一个 ONE 表示“那”，指上一行那句话。

      关系是一个表示动作的部件，加上一个标出时间或肯定否定的“指”。以 LIGHT（看见）为例：

      指意思LIGHT …
      _无时态看见
      BEFORE过去看见过
      ONE现在正看见
      AFTER将来将会看见
      PATH一直一直看着
      NOT否定看不见
      OPEN问：是否？看见了吗？

      第二个例子把“影子”那段发射写成了话：我们看见过你们；我们看不见你们了。第三个例子指向自己：你们的世界是水世界，我们看见过那个。

      5 · 数

      数是九个比特

      一个数写作 COUNT（一条计数的横线），后面的“指”按九个比特读：从 256 到 1，从左到右，从上到下。COUNT 单独出现是零，所以能写 0 到 511。只有 COUNT 这一类的“指”按比特读，所以数永远不会被错认成词。

      写作 COUNT.137。试试 137，第五段发射。

      6 · 声音

      往下叠，就是又一个声音

      只有新的一方才会在一行下面加一个声部，而且每一方一直用同一个声部，所以声部的数目就是声音的数目。下面声部里的每个部件，回应同一位置上方最近的那个部件。这样任何一方都能逐个部件地赞同、否定或修改任何节点和边。一场对话，就是几个声音一起搭起来的一张图。

      下面画的意思
      同一个部件是
      NOT不
      另一个部件换成
      空位置下面的部件还有
      什么都不画未表态

      提问：任何位置上的 OPEN 都在问“这里填什么？”，下面画的东西就取代它。最后一个例子里，第三个声音 * 在我们的 WATER 下面画了 AIR。它回应的是上方最近的部件，也就是我们的：它站在他们一边，反对我们对自己世界的说法。

      7 · 翻译机

      翻译机怎样读一页

      1. 把一页切成 3 × 3 的位置。不落在格点上的都是图，比如最早那幅 667 比特的图，而不是文字。
      2. 在三行的空隙处分出句子，数一数一句有几个声部：那就是有几个声音。
      3. 把每句的第一个声部读成一条边：节点、关系、节点。同一个词，同一个节点。单独的 ONE 指向上一行。
      4. 把下面声部的每个部件和上方最近的部件对照，把回答连同画它的声音，挂到那个节点或那条边上。

      人类不用学这些符号；翻译机负责读和写，它的词库随着每一页增长。你也可以运行同一台机器：转换器在浏览器里把文字变成图，再把图变回文字。它和命令行词典 glyph（pip install glyph-cli）用的是同一套规则和同一份词表。
