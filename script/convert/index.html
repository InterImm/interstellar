网格文字 · 转换器

文字变图，图变文字

把一页写成文字，看它画出来；或者在网格上画，再把它读回来。两个方向都会像翻译机那样，把这一页读成一张图。所有内容都不会离开你的浏览器。

原理词典转换器

转换器需要 JavaScript 和词表文件，没能加载。

文字 → 图

每行一个声部：符号: 节点 | 关系 | 节点。词写成词典里的 类.指，数写成 COUNT 加 512 进制的数位（COUNT.137；2219 写作 COUNT.4.171，也可以直接写 COUNT.2219），_ 表示空。一组行是一个三元组，第一行下面的行是其他声音在回应它。空一行开始下一个三元组。# 后面是注释。

符号：+ 是他们，× 是我们；其他任何单个字符是另一个声音。
